# SQL-Sales-BD: Анализ продаж магазина электроники
Цель проекта: проанализировать базу данных по продажам магазина электроники за 3 года в различных срезах и дать рекомендации по улучшению бизнес-метрик

## Стек технологий: 
PostgreSQL (pgAdmin)

Git 

## Группы метрик и структрура анализа
Для наглядности весь анализ разделён на три ключевых блока. 

### Метрики продаж и выручки 
Были проанализированы ключевые метрики: 
- Общая выручка, средний чек, наполненность чека
- Сезонность продаж
- Динамика выручки по годам (YoY)
- ARPPU и его динамика по месяцам 
### Ключевые выводы по продажам и выручке 
- Общая выручка за весь период составила 203 000 рублей, средний чек 1564 рубля, усреднённое количество товаров в чеке - 3 шт.
- Наблюдается сезонность с пиком продаж в марте и спадом в летние месяцы, что может быть обусловлено проведением акций от партнёров 
- По сравнению с 2023 годом, общая выручка выросла на 436%. Наибольший рост продеморстрировала категория "Mobile Devices" (+3274%), а также во всех остальных категориях наблюдается рост свыше +100%.
- Значение ARPPU непостояннно, наблюдаются скачки, что показывает на нестабильность доходов. Необходимо предпринять меры для нормализации доходов.
